# Changelog

## v0.3.7 · 2026-10-23

- 修复 运行脚本后统计行的 `formatElapsed is not defined` 报错：改用面板已有的耗时格式化函数，脚本运行记录与耗时统计恢复正常。
- 新增 **界面缩放**：设置页可选 100%–200%，选择后立即生效并自动保存；高分辨率屏幕下面板文字偏小时可调大，不再需要依赖系统级 DPI 强制缩放。
- 安装器 DPI 策略修正：不再按系统缩放比例向 CEP manifest 写入 `--force-device-scale-factor`（旧写法在旧版 CEF 上会导致中文输入法无法上屏），固定写入 `1`；需要更大界面时请使用上面的界面缩放。

## v0.3.6 · 2026-10-21

- 新增 **选择对象黑白互换**：交换选中对象已有填充、描边中的精确纯黑与纯白，灰色和彩色保持原样；支持路径、编组、复合路径和文字。Windows Illustrator 2023–2026 可使用匹配的 C++ 加速命令，普通 JSX 仍可独立运行。
- 新增 **纸杯展开**：填写上下口直径，以及实际高度 H 或斜坡长度 S，生成可编辑的杯身展开路径。提供常驻窗口、实时预览、左右搭接、自定义出血、等份辅助线和尺寸标注；按用途建立真实子图层，单独保留不含搭接与出血的闭合图案区域。当前为 JSX 工具，不含杯口卷边和封底工艺结构。
- 新增 **拼音 / 首字母搜索**：可用拼音或拼音首字母查找中文脚本名称，例如输入 `zbzk` 搜索“纸杯展开”。保留原有中文搜索；这是输入中文不便时的替代查找方式，不代表修复了 CEP 的输入法兼容问题。
- 2026-10-22 发布修订：同步 Windows 安装帮助，停用旧 Mac 手动步骤，清理开发机路径残留，补齐 Ace 许可证及公开 SHA256 校验文件。

## v0.3.1

- 支持 Illustrator 2023、2024、2025、2026 的面板加载。
- 为旧版 Illustrator 使用 legacy CEP 入口，解决 2023-2025 空白面板问题。
- 旧 CEP 下 SVG 图标改为更稳定的内联方案。
- Windows Illustrator `.aip` 成品按 2023/2024/2025/2026 分目录发布。
- 安装器默认开启 CEP 支持、安装 C++ 加速插件、创建桌面安装帮助快捷方式。
- 扫描深度改成固定下拉选项，`0` 表示仅当前目录。
- 发布包清理开发机路径、运行记录、收藏和面板尺寸。
