# 选择图层添加白色颜色叠加.jsx 说明

## 脚本用途

给 Photoshop 当前选择的图层添加 `颜色叠加` 图层样式。

## 效果

- 混合模式：正常
- 颜色：纯白 RGB 255 / 255 / 255
- 不透明度：100%
- 可重复运行：已有颜色叠加时，会继续新增一条白色颜色叠加，不覆盖旧效果。

## 使用流程

1. 在 Photoshop 中打开文档。
2. 选择一个或多个需要处理的图层。
3. 在 HGScripts 面板中运行 `选择图层添加白色颜色叠加.jsx`。

## 注意事项

- 脚本会尽量保持原来的图层选择状态。
- 没有打开文档时会静默跳过。
- Photoshop 版本需要支持同一种图层样式的多重效果。
- 运行错误会写入本机隐藏日志：`%APPDATA%\HGScripts\logs\photoshop\选择图层添加白色颜色叠加.log`。
