# 复制当前选择图层到剪贴板.jsx 说明

## 脚本用途

把 Photoshop 当前活动图层复制到系统剪贴板。

## 等效手动操作

1. 全选画布。
2. 执行 Photoshop 原生 `复制` 命令。
3. 取消选择。

## 使用流程

1. 在 Photoshop 中打开文档。
2. 在图层面板中选中需要复制的图层。
3. 在 HGScripts 面板中运行 `复制当前选择图层到剪贴板.jsx`。
4. 到目标位置粘贴。

## 注意事项

- 脚本使用 Photoshop 原生 `Ctrl+C` 口径，不使用 `合并拷贝`。
- Photoshop 普通 `复制` 只复制当前活动图层，不是合并可见图层；因此正常路径不再执行独显，以提升速度。
- 当前版本为极速路径：`全选`、`复制`、`取消选择` 都走 Photoshop Action Manager，不再做图层 ID 读取、独显、通道恢复或成功日志。
- 执行后会取消 `Ctrl+A` 产生的全画布选区。
- 当前选中多个图层时，以 Photoshop 当前活动图层为准。
- 没有打开文档时会静默跳过。
- 运行错误或单次耗时超过阈值时会写入本机隐藏日志：`%APPDATA%\HGScripts\logs\photoshop\复制当前选择图层到剪贴板.log`。
