# 粘贴剪贴板到当前图层蒙版.jsx 说明

## 脚本用途

给 Photoshop 当前活动图层创建图层蒙版，并把剪贴板内容原位粘贴到该蒙版里。

## 等效手动操作

1. 给当前活动图层创建图层蒙版。
2. 进入蒙版通道。
3. 执行 `Ctrl+Shift+V` 原位粘贴。
4. 取消选区。
5. 退出蒙版，回到正常图层显示。

## 使用流程

1. 先运行 `复制当前选择图层到剪贴板.jsx`，或手动复制需要作为蒙版的内容。
2. 选中要接收蒙版的 Photoshop 图层。
3. 在 HGScripts 面板中运行 `粘贴剪贴板到当前图层蒙版.jsx`。

## 注意事项

- 如果当前图层已经有图层蒙版，脚本会直接进入已有蒙版并原位粘贴，不重复创建第二个普通图层蒙版。
- 当前版本为极速路径：直接尝试创建蒙版，已有蒙版时继续进入现有蒙版，避免额外读取图层状态。
- 脚本会真实进入蒙版通道。这个步骤不能省略，否则 Photoshop 可能把剪贴板内容粘贴成新的像素图层，而不是写进蒙版。
- 原位粘贴使用 Photoshop Action Manager 的 `inPlace` 口径，对齐 `Ctrl+Shift+V`。
- 运行后会取消选区并切回复合颜色通道。
- 没有打开文档时会静默跳过。
- 运行错误或单次耗时超过阈值时会写入本机隐藏日志：`%APPDATA%\HGScripts\logs\photoshop\粘贴剪贴板到当前图层蒙版.log`。
