# 恢复当前文档图层可见.jsx 说明

## 脚本用途

按上次 `记录当前文档图层可见.jsx` 保存的状态，恢复 Photoshop 当前文档所有图层和图层组的可见性。

## 恢复来源

脚本会读取：

`%APPDATA%\HGScripts\data\photoshop\layer_visibility\`

里当前 PSD 对应的 JSON 记录。

## 匹配规则

恢复时优先按 `layer.id` 匹配；找不到时依次用：

- 图层层级路径和同名顺序
- 图层层级路径
- 图层索引路径

这样在图层轻微移动或存在重名时，比只按名字恢复更稳。

## 使用流程

1. 先运行过 `记录当前文档图层可见.jsx`。
2. 修改图层可见状态。
3. 需要回到记录状态时，运行 `恢复当前文档图层可见.jsx`。

## 注意事项

- 脚本静默执行，不弹窗。
- 兼容没有内置 `JSON.parse` 的 Photoshop ExtendScript 环境。
- 如果记录后新增、删除或大幅重排图层，个别图层可能无法匹配，详情写入隐藏日志。
- 运行错误会写入隐藏日志：`%APPDATA%\HGScripts\logs\photoshop\恢复当前文档图层可见.log`。
