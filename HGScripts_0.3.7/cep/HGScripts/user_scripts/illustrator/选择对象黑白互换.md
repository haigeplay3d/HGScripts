# 选择对象黑白互换

## 用途

将选中对象已有填充、描边中的纯黑和纯白互换，灰色和彩色保持原样。

## 怎么用

1. 在 Illustrator 中用选择工具选中需要处理的对象。
2. 在 HGScripts 面板点击“刷新”，搜索“选择对象黑白互换”，选中并运行。
3. 脚本静默执行；再次运行可将已交换的黑白色换回。

## 处理范围

- 支持普通路径、编组、复合路径和文字对象；文字按字符处理，保留混合字色。
- RGB：`0,0,0` 与 `255,255,255` 互换。
- CMYK：`0,0,0,100` 与 `0,0,0,0` 互换。
- 灰度：仅交换 `0` 与 `100` 两个端点。
- 填充和描边分别处理；不会新增填充或描边。
- 保留对象结构、选择状态、透明度、线宽、混合模式和叠印设置。

## 注意事项

- 只匹配精确数值。近黑、近白、复合黑、其它灰色和彩色不会转换。
- 渐变、图案、专色、Lab 颜色、图片、置入对象和符号实例保持原样。
- 锁定、隐藏、参考线和剪切路径跳过；剪切组内的普通内容仍可处理。
- 使用选择工具选中文字对象；文字编辑状态下的局部文字选择不处理。
- 普通 JSX 只能处理对象 DOM 中的基础颜色，不能完整处理复杂“外观”面板的多重
  填充、描边和效果。本脚本不会扩展外观、转曲或新增外观项。
- 这是独立 JSX，不依赖 C++ 插件。无需安装到 Illustrator 系统脚本目录。
- 也可以通过 `文件 > 脚本 > 其它脚本` 单独运行此文件。
- 隐藏日志只记录本次运行的计数、阶段和数值错误码，保存在用户数据目录下
  `HGScripts/logs/selected_black_white_swap.log`，不记录文档名称、文字或对象名称。
