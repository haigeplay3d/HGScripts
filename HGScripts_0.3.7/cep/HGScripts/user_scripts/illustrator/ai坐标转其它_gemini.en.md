# AI Coordinate Converter (Legacy Gemini)

## Purpose

Converts the selected Illustrator object position and size into AI coordinates, artboard ratio, UV, Octane, and related values. This is the legacy coordinate converter; use AI Coordinate Converter for regular work.

## How to Use
1. Open an Illustrator document.
2. Select the target artwork if required.
3. Run the script.

## Notes
- Check the result before saving production artwork.
