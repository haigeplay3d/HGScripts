# 尺寸无小数

## 用途

把当前选择对象的宽高调整为无小数尺寸。支持 C++ 加速，脚本管理器里可切换 C++ / JSX 运行模式。

## 怎么用

1. 选中需要处理的对象。
2. 运行 `尺寸无小数.jsx`。

## 处理规则

- 只处理带小数的尺寸。
- 宽有小数就只改宽，高有小数就只改高。
- 原本已经是整数的宽或高不改变。
- 处理方式不是四舍五入，而是去掉小数后加 `1`。

## 示例

| 原尺寸 | 处理后 |
| --- | --- |
| `100.2 x 80.9` | `101 x 81` |
| `100.2 x 80` | `101 x 80` |
| `100 x 80.9` | `100 x 81` |
| `100 x 80` | 不改变 |

## 注意

- 多选时逐个对象处理。
- 默认以可见尺寸为准。
- 默认保持对象中心点不变。
- 无选择、锁定对象、隐藏对象或无有效尺寸对象会静默跳过。
