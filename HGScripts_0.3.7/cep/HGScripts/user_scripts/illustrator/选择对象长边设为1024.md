# 选择对象长边设为1024

## 功能

把当前 Illustrator 选区按等比例缩放，使整个选区的最长边变为 `1024`。

## 使用方式

1. 在 Illustrator 中选中一个或多个对象。
2. 运行脚本 `选择对象长边设为1024.jsx`。
3. 脚本静默执行，不弹窗；无选择、无文档或对象不可编辑时会直接跳过。

## 规则

- 多选时按 Illustrator 当前选区整体处理，效果等同于在属性/变换面板锁定比例后缩放整个选区。
- 优先调用 Illustrator 原生 Scale 动作做等比例缩放，不直接分别写入宽高。
- 宽高使用同一个原生缩放比例，不会单独拉伸宽或高。
- 缩放中心使用 Illustrator 原生 Scale 的中心点。
- 尺寸口径跟随 Illustrator 属性/变换面板常用口径；开启预览边界时，边界计算跟随 `includeStrokeInBounds`。
- 已经接近长边 `1024` 的对象不会重复处理。
- 锁定、隐藏、参考线、锁定图层或隐藏图层中的对象会跳过。

## 运行方式

脚本为日常极速入口，只调用 C++ 命令执行，不写运行日志。需要排查尺寸口径时，
使用 `tools/illustrator/user_scripts_archive/诊断工具/记录长边1024对照_左.jsx` /
`tools/illustrator/user_scripts_archive/诊断工具/记录长边1024对照_右.jsx`。
