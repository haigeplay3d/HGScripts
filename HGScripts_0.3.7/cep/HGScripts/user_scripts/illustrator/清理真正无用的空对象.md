# 清理真正无用的空对象

## 用途

清理 Illustrator 文档里确定没有显示效果、也没有结构用途的空对象。

脚本会优先尝试 HGScripts 的 C++ 加速命令；如果没有安装加速插件，或面板运行模式设置为 JSX，会使用 JSX 方式执行同一套保守规则。

## 会清理什么

- 没有填充、没有描边、不是剪切蒙版、不是参考线的普通路径。
- 内容为空或只有空白字符的文字对象。
- 所有子路径都无填充、无描边、无结构用途的复合路径。
- 子对象清理后已经为空的组。
- 只剩无内容剪切蒙版残留的剪切组。

## 不会主动处理什么

- 锁定对象、隐藏对象、锁定图层、隐藏图层里的对象。
- 置入图、位图、网格、符号、图表等不适合用空路径规则判断的对象。
- 仍然有剪切、参考线或可见内容用途的对象。

## 注意

这是自动删除脚本。正式处理重要文件前，建议先保存一份副本。

脚本默认静默执行，不弹窗；运行记录写入 HGScripts 的隐藏运行日志。
