# 当前画板创建黑色背景矩形

## 用途

在当前活动画板上创建一个和画板一样大的黑色背景矩形。

## 怎么用

1. 打开 Illustrator 文档。
2. 激活要添加背景的画板。
3. 运行 `当前画板创建黑色背景矩形.jsx`。

## 结果

- 创建黑色填充、无描边的矩形。
- 矩形尺寸与当前画板一致。
- 正常情况下创建到当前可写图层，并放到该图层底层。
- 如果当前图层锁定、隐藏或不可修改，会自动新建 `HGScripts 背景` 图层并放到底层后再创建矩形。

## 注意事项

- 不会自动删除已有背景。
- 如果重复运行，会创建多个背景矩形。
- 如果 Illustrator 返回图层不可写等异常，会静默记录到用户数据目录下的 `HGScripts/logs/artboard_background.log`。
