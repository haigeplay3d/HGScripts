# HGScripts v0.3.7 更新说明

2026-10-23 发布。本版是修复与体验更新：修复脚本运行统计报错，新增界面缩放，并修正安装器的 DPI 写入策略以恢复中文输入法。

## 1. 修复：运行脚本后报错 formatElapsed is not defined

v0.3.6 中运行脚本后，面板统计行会报 `formatElapsed is not defined`，运行耗时与计数显示中断。本版修复该问题，脚本运行统计恢复正常。

## 2. 界面缩放

设置页新增“界面缩放”，可选 100% / 125% / 150% / 175% / 200%。

- 选择后立即生效并自动保存，下次打开面板保持。
- 高分辨率屏幕下面板文字偏小时可直接调大，不再依赖系统级强制缩放。

## 3. 安装器 DPI 策略修正（中文输入法恢复）

旧版安装器会按系统缩放比例（例如 150%）向 CEP manifest 写入 `--force-device-scale-factor=1.5`。该写法在旧版 CEF 内核上会让中文输入法无法上屏（英文和粘贴可输入）。

本版安装器固定写入 `1`，中文输入法恢复正常；需要更大界面时配合使用“界面缩放”。

## 升级与兼容

- 使用本版 Windows 安装器覆盖安装即可升级；升级前保存工作并关闭 Adobe 宿主，安装后重新打开。
- Illustrator 2023、2024、2025、2026 随包提供各年份匹配的统一 `HGScriptsNative.aip`；不要混用年份。
- Illustrator 2021 保留有限 CEP / JSX 支持，不提供 AIP 加速；Illustrator 2020 不在兼容目标内。
- 当前正式安装包面向 Windows，macOS 暂不支持。
- 正式发布物为安装器、独立卸载器和安装说明。公开导出可包含面板、JSX、文档和 AIP 成品，不包含 C++ 源码、SDK、VS 工程、调试符号或本机运行记录。
