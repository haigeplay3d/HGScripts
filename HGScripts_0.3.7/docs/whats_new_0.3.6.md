# v0.3.6 新功能上手

本版新增“选择对象黑白互换”“纸杯展开”和拼音 / 首字母搜索。升级前保存工作并关闭 Adobe 宿主，安装后重新打开，让新版面板和插件加载。

## 快速找到新工具

在 Illustrator 中打开 HGScripts，点击“刷新”，再搜索工具名称。

也可以直接输入拼音或首字母：

| 要找的工具 | 拼音 | 首字母 |
| --- | --- | --- |
| 纸杯展开 | `zhibeizhankai` | `zbzk` |
| 选择对象黑白互换 | `xuanzeduixiangheibaihuhuan` | `xzdxhbhh` |

中文搜索继续保留。拼音搜索是另一种查找方式，不是中文输入法兼容问题的修复。

## 选择对象黑白互换

1. 用选择工具选中需要处理的路径、组、复合路径或文字对象。
2. 搜索并运行“选择对象黑白互换”。
3. 已有填充和描边中的精确纯黑、纯白互换；再次运行可以换回。

灰色和彩色不变，近黑、近白、复合黑、渐变和专色不在处理范围。文字应选择整个文字对象，文字编辑状态中的局部选字不处理。

Windows Illustrator 2023–2026 安装匹配年份的加速插件后，可以使用对应的 C++ 命令；没有加速插件时，普通 JSX 也能完成同一项黑白互换。

## 纸杯展开

1. 搜索并运行“纸杯展开”，打开常驻生成器。
2. 填上口、下口直径，以及 H 实际高度或 S 斜坡长度；这两项会互相计算。
3. 按需设置左右搭接、出血、等份辅助线和标注。
4. 勾选“预览”查看结果，点击“生成纸样”保留正式纸样。

展开图上量到的杯壁长度是 S；例如上口 90、下口 60、H 100 mm 时，S 约为 101.12 mm。

生成结果按用途分层。“图案区域”是单独闭合路径，不含搭接与出血，方便对齐或手动制作剪切蒙版。它不自动贴图或变形。当前纸杯工具为 JSX，没有纸杯 C++ 版。

工具只生成杯身，不含卷口、杯底或封底工艺余量。打印时使用 100% / 实际大小，先打样核对。预览会写入临时对象，可能影响文档的未保存状态和撤销历史；关闭预览会清理本工具的临时对象，正式纸样保留。

纸杯功能当前已在 Illustrator 2026 实测，不能据此保证其它年份或实物生产效果。更详细的参数说明可在面板中查看脚本同名说明。
