## v0.3.9 · 2026-11-04

本版两大主题：**脚本目录重做**（原「目录管理」）与**面板尺寸彻底修复**（可拖更小、不再自动放大）。

### 脚本目录

- 「目录管理」改为「脚本目录」并分成三段（目录列表 / 使用中的目录 / 高级）；每个目录新增「打开文件夹」按钮，点一下直接跳到该目录放脚本，不用自己找路径。
- 脚本目录路径改为只读展示，点一下复制完整路径；需要改路径时点「更改…」，改完点别处自动保存，不再需要点「保存修改」。
- 「扫描范围」改为每个目录单独设置（原来所有目录共用一个值），目录行直接显示当前深度；目录里一个脚本都没有时，面板会说明是路径失效、脚本藏在子文件夹，还是目录里确实没有 .jsx / .js。
- 新增「添加脚本文件…」和拖拽区：选一个 .jsx / .js 或把文件拖进弹窗，自动添加它所在的文件夹；「忽略目录」收进「高级」折叠区并注明对所有目录生效，全屏只保留一个「保存」按钮。
- 顶部工具栏按钮文案恢复为「添加目录」（4 字），不再显示「添加文件夹」把这一行挤满；弹窗内的添加按钮仍写「添加文件夹…」，悬停提示改为「管理脚本目录」。

### 面板尺寸

- 修掉「面板宽度改不动」的真正原因：面板声明里写的最小尺寸 300 是逻辑像素，在 150% 缩放的屏幕上会被放大成 450，把窗口死死卡住。现在最小尺寸按实际需要重新声明，窗口可以正常拖到下限。
- 面板可以拖得更小，拖到多小下次启动就原样恢复多小：修掉了代码里写死的尺寸下限——你拖出来的更小尺寸会被它偷偷换成更大的值存进记忆，下次打开就「恢复」成放大版，看起来像面板自己变大。现在只有你手动拖出来的尺寸才会被记住，Illustrator 自己改的尺寸一律不记。
- Illustrator 在启动或停靠变化时自己改面板尺寸，面板会压回你上次的尺寸；被压回时的尺寸也不会写进记忆。
- 点「添加目录」时：窄面板切到你上次的宽面板尺寸（记忆多宽就切多宽，不做临时加宽），宽面板则保持不动；关闭弹窗（关闭按钮 / 点遮罩 / Esc 三种都一样）后回到窄面板。
- 右上角 Ai 图标在「窄面板」与「宽面板」之间来回切换，两边都用你上次拖出来的尺寸，不再固定切到某个数值；当前算宽还是窄，按右侧详情区是否出现来定（与肉眼看到的一致）。
- 首次安装第一次打开面板时以推荐尺寸启动（完整显示标题、顶栏、6 个脚本行和状态栏）；此后每次打开 Illustrator 沿用上一次的模式和尺寸——上次停在窄面板就开窄的，停在宽面板就开宽的。
- 面板缩窄时「最近使用」下拉会跟着一起收窄：修掉了全局写死的内容最小宽度，原来面板拖窄时布局仍按旧宽度排版，右侧「收藏 / 默认 / 新建 / 添加目录」直接被裁掉，看起来就像下拉占满一行、按钮消失了。
- 面板较窄时整条顶栏自动降一档字号与内边距，按钮不再挤占搜索框和「最近使用」下拉的宽度。

## v0.3.8 · 2026-11-02

- 新增 **启动时检查更新**：面板启动约 8 秒后静默检查一次是否有新版本（读取官网版本信息文件，8 秒超时），发现新版本时在面板底部显示提示条并带版本号，点击直达官网下载页；已是最新、断网或检查失败时完全静默，不影响面板使用。
- 更新提示支持关闭：提示条右侧新增「×」，关闭后 7 天内不再提醒（写入 `settings.updateSnoozeUntil`），7 天后如有新版本会重新提示；点击提示文字本身仍会跳转下载页。
- 「关于」页新增「检测更新」开关：默认开启（`settings.updateCheckEnabled`），取消勾选后启动不再检查；重新勾选时立即检测一次，并显示检测中 / 已是最新 / 检测失败的结果反馈。
- 「关于」页的版本号与更新日期改为随安装版本自动读取，不再写死在页面里。
- 版本号比较改为按数字逐段比对，避免 0.3.10 与 0.3.9 这类多位数版本被误判为已最新。
- 网站侧版本信息收敛为单一数据源（`hgscripts.releases.json`），版本号、GitHub 链接与 `version.json` 全部由它生成，发版只需改一处。
- v0.3.7 及更早版本的面板没有更新检查功能，本版起才能收到后续版本的自动提醒。

## v0.3.7 · 2026-10-23

- 修复 运行脚本后统计行的 `formatElapsed is not defined` 报错：改用面板已有的耗时格式化函数，脚本运行记录与耗时统计恢复正常。
- 新增 **界面缩放**：设置页可选 100%–200%，选择后立即生效并自动保存；高分辨率屏幕下面板文字偏小时可调大，不再需要依赖系统级 DPI 强制缩放。
- 安装器 DPI 策略修正：不再按系统缩放比例向 CEP manifest 写入 `--force-device-scale-factor`（旧写法在旧版 CEF 上会导致中文输入法无法上屏），固定写入 `1`；需要更大界面时请使用上面的界面缩放。
- 2026-11-01 发布修订：为 37 个 Illustrator 脚本各配一枚独立的绿色系图标，替代原来统一的默认图标；补齐 README 中文图文目录；带 C++ 加速的脚本，其「编辑说明」按钮图标替换为绿色闪电（原为文档图标），悬停提示注明 C++ 模式 / 强制 JSX。同步当前正式面板与 2026 AIP，重新构建 Windows 安装三件套。
- 2026-11-01 发布修订：Windows 安装器与卸载器合并为同一个 `HGScripts-v0.3.7-Setup.exe`，首页可切换“安装／更新”和“卸载”模式；不再单独发布 `HGScripts-Uninstall.exe`，Windows“应用和功能”卸载入口继续保留。

## v0.3.6 · 2026-10-21

- 新增 **选择对象黑白互换**：交换选中对象已有填充、描边中的精确纯黑与纯白，灰色和彩色保持原样；支持路径、编组、复合路径和文字。Windows Illustrator 2023–2026 可使用匹配的 C++ 加速命令，普通 JSX 仍可独立运行。
- 新增 **纸杯展开**：填写上下口直径，以及实际高度 H 或斜坡长度 S，生成可编辑的杯身展开路径。提供常驻窗口、实时预览、左右搭接、自定义出血、等份辅助线和尺寸标注；按用途建立真实子图层，单独保留不含搭接与出血的闭合图案区域。当前为 JSX 工具，不含杯口卷边和封底工艺结构。
- 新增 **拼音 / 首字母搜索**：可用拼音或拼音首字母查找中文脚本名称，例如输入 `zbzk` 搜索“纸杯展开”。保留原有中文搜索；这是输入中文不便时的替代查找方式，不代表修复了 CEP 的输入法兼容问题。
- 2026-10-22 发布修订：同步 Windows 安装帮助，停用旧 Mac 手动步骤，清理开发机路径残留，补齐 Ace 许可证及公开 SHA256 校验文件。
