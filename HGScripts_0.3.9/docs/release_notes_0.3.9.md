# HGScripts v0.3.9 更新说明

2026-11-04 发布。本版两大主题：**脚本目录重做**（原「目录管理」）与**面板尺寸彻底修复**（可以拖得更小、不再自动放大）。

## 1. 脚本目录重做

原「目录管理」弹窗改为「脚本目录」，分成三段：目录列表 / 使用中的目录 / 高级。

- 每个目录新增「打开文件夹」按钮，点一下直接跳到该目录放脚本，不用自己找路径。
- 目录路径改为只读展示，点一下复制完整路径；需要改路径时点「更改…」，改完点别处自动保存，不再需要点「保存修改」。
- 「扫描范围」改为每个目录单独设置（原来所有目录共用一个值），目录行直接显示当前深度。
- 目录里一个脚本都没有时，面板会说明是路径失效、脚本藏在子文件夹，还是目录里确实没有 .jsx / .js。
- 新增「添加脚本文件…」和拖拽区：选一个 .jsx / .js 或把文件拖进弹窗，自动添加它所在的文件夹。
- 「忽略目录」收进「高级」折叠区并注明对所有目录生效，全屏只保留一个「保存」按钮。
- 顶部工具栏按钮文案恢复为「添加目录」（4 字），不再把顶栏挤满。

## 2. 面板尺寸彻底修复

- **修掉「每次打开面板都自己变大」**：面板代码里写死了一个尺寸下限，你拖出来的更小尺寸会被它偷偷换成更大的值存进记忆，下次打开就「恢复」成放大版。现在拖到多小就记多小、开多小；只有你手动拖出来的尺寸才会被记住。
- **修掉「面板宽度卡死拖不动」**：面板声明里写的最小尺寸是逻辑像素，在系统缩放 150% 的屏幕上会被放大 1.5 倍，把窗口死死卡住。已按实际需要重新声明，窗口可以正常拖到下限。
- Illustrator 在启动或停靠变化时自己改面板尺寸，面板会压回你上次的尺寸。
- 点「添加目录」时：窄面板自动切到你上次的宽面板尺寸，关闭弹窗后回到窄面板；已经处于宽面板则保持不动。
- 右上角 Ai 图标在「窄面板」与「宽面板」之间来回切换，两边都用你上次拖出来的尺寸。
- 面板缩窄时「最近使用」下拉跟着一起收窄，右侧按钮不再被裁掉；较窄时顶栏自动降一档字号。

## 升级与兼容

- 使用本版 Windows 安装器覆盖安装即可升级（同版本号 AppId 直接覆盖，无需先卸载）；升级前保存工作并关闭 Adobe 宿主，安装后重新打开。
- **升级后第一次打开面板，尺寸沿用你上次的设置**；本版解除了代码里的尺寸下限，如觉得面板偏小或偏大，手动拖到喜欢的位置松手即可，之后每次启动都保持。
- v0.3.8 及以后版本的面板会在启动约 8 秒后自动检查更新；发现新版本时面板底部会出现提示条，点击直达下载页。
- Illustrator 2023、2024、2025、2026 随包提供各年份匹配的统一 `HGScriptsNative.aip`；不要混用年份。
- Illustrator 2021 保留有限 CEP / JSX 支持，不提供 AIP 加速；Illustrator 2020 不在兼容目标内。
- 当前正式安装包面向 Windows，macOS 暂不支持。

## 添加自己的脚本

方式一：把 .jsx / .js 文件放入内置脚本目录：

```text
%APPDATA%\Adobe\CEP\extensions\HGScripts\user_scripts\illustrator
```

方式二：把脚本集中放在一个独立文件夹，在面板中点击「添加目录」选择它。无需逐个导入，也无需手动刷新。
