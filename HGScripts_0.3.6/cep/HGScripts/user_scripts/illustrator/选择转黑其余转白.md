# 选择转黑其余转白

## 用途

把当前画板内选中的对象转成黑色，其它有颜色的对象转成白色。

适合快速制作反向黑白遮罩。

## 怎么用

1. 打开 Illustrator 文档。
2. 激活要处理的画板。
3. 选中要保留为黑色的对象。
4. 运行 `选择转黑其余转白.jsx`。

## 结果

- 选中对象已有填充或描边会变黑。
- 当前画板内其它有颜色对象会变白。
- 没有填充、没有描边的位置不会新增颜色。
- 本次实际改色的对象，不透明度会恢复为 100%。

## 注意事项

- 这是批量改色脚本，会直接修改当前画板内容。
- 建议先复制文件或在副本中测试。
- 只处理当前活动画板内对象。
- 不会执行“扩展外观”，不会拆散原有对象结构。
