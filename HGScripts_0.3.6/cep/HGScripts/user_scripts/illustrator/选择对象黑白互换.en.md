# Swap black and white in selected objects

## Usage

Select objects with the Selection tool. Click Refresh in HGScripts, find
"Swap Black and White in Selection", select it and run. The script runs silently.
Run it again to swap the converted colors back. You can also run the JSX through
Illustrator's `File > Scripts > Other Script` menu.

## Behavior

- Swaps existing solid fills and strokes in paths, groups, compound paths and
  text objects. Mixed text colors are handled character by character.
- Exact RGB endpoints: `0,0,0` and `255,255,255`.
- Exact CMYK endpoints: `0,0,0,100` and `0,0,0,0`.
- Grayscale endpoints: `0` and `100` only.
- Preserves other colors, selection, structure, opacity, stroke width, blending
  and overprint settings. Does not add fills or strokes.
- Skips near-black/near-white, rich black, intermediate grays, gradients,
  patterns, spots, Lab colors, images, placed art and symbol instances.
- Skips locked/hidden objects, guides and clipping paths. Ordinary content
  inside a clipping group can still be processed.
- Select text objects with the Selection tool; partial text-edit selections
  are not processed.

This standalone JSX does not require a C++ plugin. Basic DOM colors are
supported; complex Appearance stacks and effects are not fully accessible.
The script does not expand appearances or outline text.

A private last-run log contains counts, stages and numeric error codes only,
under the user-data directory at `HGScripts/logs/selected_black_white_swap.log`.
Document names, object names and text contents are not recorded.
