# 选择对象转自定义颜色

## 用途

把当前选中对象已有的填充或描边改成你选择的颜色。

## 怎么用

1. 打开 Illustrator 文档。
2. 选中要改色的对象。
3. 运行 `选择对象转自定义颜色.jsx`。
4. 在拾色器中选择颜色并确认。

## 结果

- 有填充的对象，填充改为所选颜色。
- 有描边的对象，描边改为所选颜色。
- 没有填充或描边的位置不会新增颜色。
- 会尝试处理当前选中编组自身已有的外观填色和已有描边，同时递归处理组内子对象。
- 本次实际改色或命中选中外观通道的对象，不透明度会恢复为 100%。

## 注意事项

- 只处理当前选中对象。
- 组、复合路径和文字会尽量处理。
- 不会执行“扩展外观”，不会拆散原有对象结构。
- 取消拾色器时不会改色。
