# 单一色转自定义色_其它转自定义色

## 用途

以第一个选择对象的单一颜色为样本，把样本色改成第一个自定义颜色，把其它已有颜色改成第二个自定义颜色。支持 C++ 加速，脚本管理器里可切换 C++ / JSX 运行模式。

## 怎么用

1. 选中一个取样对象。
2. 运行 `单一色转自定义色_其它转自定义色.jsx`。
3. 第一次颜色选择器选择“样本色要转成的颜色”。
4. 第二次颜色选择器选择“其它颜色要转成的颜色”。

## 匹配规则

- 样本只有填充、只有描边，或填充和描边同色时才执行。
- 文档中所有可处理对象都会被扫描。
- 等于样本色的已有填色/描边改成第一个自定义颜色。
- 不等于样本色的已有填色/描边改成第二个自定义颜色。
- 不新增填色、不新增描边。
- 本次实际改色对象及其父级容器，不透明度会恢复为 100%。

## 注意

- 组、复合路径和普通路径会递归处理。
- C++ 模式会尽量处理复杂 Appearance paint field，不执行“扩展外观”，不拆对象结构。
- JSX 模式保持独立实现，但普通 JSX DOM 无法直接改复杂 Appearance；遇到复杂外观可改用自动/C++模式。
- 无效取样会静默退出，不弹窗。
