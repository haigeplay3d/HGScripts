# 纸杯展开

## 用途

填写纸杯的上口直径、下口直径，以及实际高度 H 或斜坡长度 S，生成可编辑的杯身展开轮廓，方便制作设计稿或打印纸样。

适用于杯壁笔直的理想圆台，以及上下直径相同的圆柱。上口直径须大于或等于下口直径，两个直径和高度都须大于 0。

## 怎么用

1. 在 Illustrator 中运行 `纸杯展开.jsx`，打开常驻窗口。可以保持窗口打开，继续操作画板；再次运行脚本会显示现有窗口。
2. 在“尺寸与搭接”页，以毫米填写 **A 上口直径**、**B 下口直径**，以及 **H 实际高度** 或 **S 斜坡长度**。H 是两处测量圆之间的垂直距离；S 沿倾斜杯壁测量。修改 H 会计算 S，修改 S 会计算 H，以最后修改的高度项为准；之后修改上、下口直径时，保留该项并重新计算另一项。各尺寸应对应同一段杯身，避开卷口和底脚。
3. 填写侧边搭接宽度，并选择左侧或右侧。默认宽度 `0`，不加搭接。需要出血时填写出血宽度；出血沿杯身边界向外生成，**不包住搭接外缘**。
4. 在“辅助与标注”页，设置两种等份数和需要的参考线、圆心、中心十字、尺寸标注或说明文字。等份数可直接填写，也可用输入框右侧的 ▲ / ▼ 每次增加或减少 1；各开关独立控制。
5. 激活目标文档和画板，勾选“预览”查看实际尺寸的临时纸样。改尺寸或选项后会更新；取消预览或关闭窗口会清除临时纸样。没有文档时，先打开文档以预览，或直接点击“生成纸样”新建 CMYK 文档。
6. 点击“生成纸样”保留正式纸样。窗口继续打开，可调整参数并生成下一份；正式纸样不会随之后的预览修改。数字支持小数、全角输入，也可带 `mm` 单位，例如 `80.5`、`８０.５` 或 `80.5 mm`。

界面右侧的卷好纸杯与摊平纸片图只是尺寸概念示意，实际预览绘制在画板上。绿色 **H 实际高度** 是杯子直立时的垂直距离；橙色 **S 斜坡长度** 是沿倾斜杯壁、在展开纸片内外弧之间量得的长度。例如上口 `90 mm`、下口 `60 mm`、H 为 `100 mm` 时，S 约为 `101.12 mm`，因此不能用纸片上的这段长度直接核对 H。上下口等径时，H 与 S 相同。输入 S 时，它必须大于上、下口直径差的一半，否则不能形成有实际高度的杯身；非法或尚未填完的尺寸会提示，并清除过期预览。

界面会随打开时的 HGScripts 面板语言显示中文或英文。

## 辅助线和标注

- **角度方向等分**：圆台按圆心角均分，生成指向共同圆心的径向虚线，线段限于杯身内。上下口等径时，按矩形宽度生成竖向等分线。
- **杯壁方向等分**：沿 S 等距离分层，生成同心弧虚线；等径时，按矩形高度生成横向等分线。这里按距离等分，不按面积等分。
- 两种等份数均为 `1–100` 的整数。填 `1` 不加该类等分线；填 `4` 添加 `3` 条内部等分线。▲ / ▼ 不会越过该范围，勾选预览时调节会实时更新。搭接与出血不参与等分。
- **圆心 O**：标记两条弧共同的圆心，可能在画板外；上下口等径时此项不可用。接近等径时圆心可能非常远，超出支持范围会保留纸样、略去圆心并在状态栏说明。
- **杯身中心十字**：用实线十字标记现有中心线上、上下两条弧之间的中点；不计算搭接与出血，也不是圆心 O。
- **尺寸标注**：标明上弧长、下弧长和斜坡长度 S；弧长不包含搭接。等径时，上下边标出对应周长。
- **中心虚线**与**纸样说明文字**各自开关；说明文字中仍列出 H 和 S。

## 生成结果

- 在新的独立图层中生成可编辑、闭合的黑色外围裁切线，并以当前画板为中心放置。
- 每份纸样保留一个总图层，内部按用途建立真正的子图层：裁切轮廓、图案区域、出血轮廓、搭接侧缝、径向等分线、同心等分线、中心虚线、杯身中心十字、圆心 O、尺寸标注、纸样说明文字。只为本次实际生成的内容建层，可分别隐藏或锁定；临时预览采用相同结构。
- **图案区域**始终生成，是不含搭接和出血的杯身主体闭合路径：圆台为扇环，上下口等径时为矩形。它在独立的“图案区域”子图层中，以无填充、蓝色细实线显示，可单独选取用于排版对齐，或自行用作剪切蒙版路径；脚本不会自动创建蒙版或修改已有设计稿。即使搭接为 `0`、与裁切线重合，它仍是独立路径。
- 添加搭接时，外围裁切轮廓包含搭接部分，原侧缝以蓝色虚线表示。
- 出血用独立的洋红色虚线轮廓表示，与黑色裁切线区分。它是排版参考，不会自动扩展或裁切已有设计稿。
- 图案区域轮廓、尺寸线、文字、中心标记、出血和蓝色虚线都只供参考；裁切时沿黑色杯身裁切轮廓，忽略外侧尺寸线。
- 图形超出画板时不会自动缩小。需要完整输出时，请换用更大的画板。
- 预览会实际添加并更新临时图形，可能影响文档的未保存状态和撤销历史；关闭预览会移除本工具的临时图形，保留用户另外添加的图形，不保证撤销历史恢复为打开前的状态。正式设计稿仍建议放在预览总图层之外。

## 打印与制作

- 打印时选择 **100% / 实际大小**，关闭“适合页面”等缩放选项。
- 先打印纸样，核对尺寸和搭接效果，再用于正式制作。纸张厚度、粘合与成型工艺可能需要额外补偿。
- 这里只生成杯身展开，不生成杯口卷边、杯底、底脚或其它工艺结构。
