# HGScripts v0.3.6 更新说明

构建始于 2026-10-21；2026-10-22 完成发布收尾。

发布修订同步了 Windows 安装帮助，停用旧 Mac 手动步骤，清理开发机路径残留，并补齐第三方许可证与 SHA256 校验文件。原生插件仅调整构建选项，业务源码未变。

本次新增两个 Illustrator 工具，并增加拼音 / 首字母搜索。两项脚本随 HGScripts 一起提供。

## 1. 选择对象黑白互换

选中对象后运行“选择对象黑白互换”，即可将已有填充、描边中的精确纯黑与纯白互换；其它灰色和彩色保持原样。

- 支持普通路径、编组、复合路径和文字；文字按字符处理。
- 不新增填充或描边，保留透明度、线宽、叠印和对象结构。
- 近黑、近白、复合黑、渐变、图案、专色等不在互换范围；这不是整张图的反相功能。
- Windows Illustrator 2023–2026 可使用对应年份统一 AIP 中的 C++ 命令；未安装加速插件或使用 JSX 模式时，脚本仍能独立完成处理。

## 2. 纸杯展开

填写上口直径、下口直径，以及 **H 实际高度** 或 **S 斜坡长度**，生成可编辑的杯身展开轮廓，便于排版和纸样打样。

- H、S 均可输入，以最后修改项为准计算另一项。
- 常驻窗口和实时预览，生成后保留正式纸样。
- 搭接宽度可调、左右可选；自定义出血沿杯身生成，不包住搭接外缘。
- 支持径向 / 杯壁方向等份辅助线、圆心、中心十字和尺寸标注。
- 按用途生成真实子图层，可分别显隐、锁定；独立闭合的“图案区域”不含搭接和出血。
- 当前为 JSX 工具，没有纸杯 C++ 版；不自动贴图或变形，不含杯口卷边、杯底和封底工艺余量。

纸杯工具的真实宿主验收目前覆盖 Illustrator 2026；其它年份与实物裁样不作已验证承诺。打印纸样时使用 100% / 实际大小，并先打样核对。

## 3. 拼音 / 首字母搜索

中文脚本名称可以用完整拼音或拼音首字母搜索。例如输入 `zhibeizhankai` 或 `zbzk` 查找“纸杯展开”。普通中文搜索继续保留。

该功能方便英文键盘输入，或中文输入法偶发无法在 CEP 搜索框中键入时查找脚本；不代表修复输入法本身的兼容问题。多音字按词库中的常用读音匹配。

## 升级与兼容

- 使用本版 Windows 安装器升级；升级前保存工作并关闭 Adobe 宿主，安装后重新打开。
- Illustrator 2023、2024、2025、2026 随包提供各年份匹配的统一 `HGScriptsNative.aip`；不要混用年份。
- Illustrator 2021 保留有限 CEP / JSX 支持，不提供 AIP 加速；Illustrator 2020 不在兼容目标内。
- 当前正式安装包面向 Windows，macOS 暂不支持。
- 正式发布物为安装器、独立卸载器和安装说明。公开导出可包含面板、JSX、文档和 AIP 成品，不包含 C++ 源码、SDK、VS 工程、调试符号或本机运行记录。

详细使用方法见脚本的同名说明，以及 [v0.3.6 新功能上手](whats_new_0.3.6.md)。
