# macOS 支持状态

版本：v0.3.6
更新日期：2026-10-22

当前 HGScripts 正式版仅面向 Windows，**macOS 暂不支持**。尚未完成 macOS 实机验收，不提供 Mac 安装包、手动安装指引或技术支持。

Windows 安装器和卸载器（`.exe`），以及随包的 Windows Illustrator C++ 加速插件（`.aip`），均不能在 macOS 上使用。

旧的未经验证的手动安装说明已停用。本文件保留原文件名，避免旧链接失效，不再提供安装命令或操作步骤。

Windows 用户请查看 [Windows 安装帮助](install_windows.md)。
