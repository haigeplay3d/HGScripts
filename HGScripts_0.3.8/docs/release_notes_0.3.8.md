# HGScripts v0.3.8 更新说明

2026-11-02 发布。本版新增面板内更新检查：以后有新版本时，面板会自己提醒你，不用再来官网查看。

## 1. 启动时检查更新

面板启动约 8 秒后会静默检查一次是否有新版本（访问海哥官网的版本信息文件）。

- 发现新版本时，面板底部显示绿色提示条「发现新版本 vX.Y.Z」，点击直接打开官网下载页。
- 已是最新版本、断网、超时或检查失败时完全静默，不弹窗、不打扰，不影响面板正常使用。
- 每次启动只检查一次。

## 2. 提示条可关闭，7 天内不再提醒

提示条右侧新增「×」关闭按钮。

- 点击「×」只关闭提示，不会打开网页；点击提示文字本身才会跳转下载页。
- 关闭后 7 天内启动面板不再弹出同一条提示，7 天后如有新版本会重新提示。

## 3. 「关于」页新增「检测更新」开关

「关于」页版本号后新增「检测更新」勾选项，默认开启。

- 取消勾选后，面板启动时不再检查更新。
- 重新勾选时会立即检测一次，并显示检测中 / 已是最新 / 检测失败的结果反馈。

## 升级与兼容

- 使用本版 Windows 安装器覆盖安装即可升级（同版本号 AppId 直接覆盖，无需先卸载）；升级前保存工作并关闭 Adobe 宿主，安装后重新打开。
- v0.3.7 及更早版本的面板没有更新检查功能，这批用户本次升级仍需从官网或网盘手动下载；从本版起即可收到后续版本的自动提醒。
- Illustrator 2023、2024、2025、2026 随包提供各年份匹配的统一 `HGScriptsNative.aip`；不要混用年份。
- Illustrator 2021 保留有限 CEP / JSX 支持，不提供 AIP 加速；Illustrator 2020 不在兼容目标内。
- 当前正式安装包面向 Windows，macOS 暂不支持。
