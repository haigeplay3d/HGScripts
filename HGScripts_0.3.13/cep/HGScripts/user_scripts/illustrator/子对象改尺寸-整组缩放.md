# 子对象改尺寸-整组缩放

原名「手选基准缩放」，2026-11-10 改为现名，与「子对象对齐画板-整组移动」同系列：
选中的是组内子对象，实际缩放的是它所属的整个父组。

## 用法

1. 在 Illustrator 中手动选中组内 1 个子对象作为基准对象。
2. 运行脚本。
3. 在弹窗里填写目标宽度、目标高度，输入框默认留空；二者可以只填一个，也可以两个都填。
4. 脚本找到该对象所属的最外层父组并缩放整个父组；只填一项时为等比缩放。
5. 缩放后保持基准对象中心坐标不变，运行前的选择也会恢复。

## 静默规则

- 保留目标尺寸输入框。
- 宽度和高度合并在同一个入口里输入。
- 不弹出成功提示。
- 无文档、未选中或选中多个对象时直接返回，不弹窗。

## 双输入规则

- 只填宽度：按目标宽度等比缩放。
- 只填高度：按目标高度等比缩放。
- 同时填写宽度和高度：允许非等比缩放，让基准对象达到指定宽高。

## 支持的输入

- `1024`：按 `1024 px/pt` 处理。
- `1024px`
- `1024pt`
- `1024mm`
- `10cm`
- `4in`

## 两层各自独立

- **自动 / C++ 模式**：脚本把菜单命令派发给插件后立即返回；插件弹自己的原生输入框并独立完成缩放，运行后自行恢复基准中心与选区。
- **强制 JSX 模式**，或插件不可用时：脚本弹自己的输入框，并用原生 Action / `resize()` 两级兜底独立完成缩放。
- 删掉任一层，另一层仍能完成全部功能。插件菜单命令独立运行时同样会自己弹输入框，不依赖脚本传参。

## 当前限制

- 只处理单选。
- 多层组默认缩放最外层父组。
- 不自动识别灰色底框，用户选中的对象就是基准对象。
- 如果深层隔离模式导致父组无法变换，请退出隔离模式后再运行。
