# 子对象改坐标-整组移动

2026-11-12 新增，与「子对象改尺寸-整组缩放」同系列：选中的是组内子对象，实际移动的是
它所属的整个父组。输入目标 X / Y，脚本平移整个父组，让选中子对象的中心落到目标坐标。

## 用法

1. 在 Illustrator 中手动选中组内 1 个子对象作为基准对象。
2. 运行脚本。
3. 弹窗里 X、Y 已经填好当前坐标；改哪个就动哪个轴，留空表示该轴不动。
4. 脚本找到该对象所属的最外层父组并平移整个父组。
5. 运行前的选区会恢复。

## 坐标口径

- 定位点：对象边界中心，与变换面板默认参考点一致。
- 原点：对象中心所在画板的左上角；X 向右为正，Y 向下为正。
- 边界：跟随 Illustrator「使用预览边界」首选项，决定边界是否计入描边。
- 多画板：优先取对象中心所在画板；对象落在画板外时取最近的画板。

## 支持的输入

- `120`：按 120 px/pt 处理。
- `-30`：允许负数，可以移到画板外。
- `50mm`、`5cm`、`2in`、`10pt`、`100px`。
- 留空：该轴不动。两个都留空则不执行。

## 静默规则

- 只有目标坐标一个输入框，不弹成功提示、无音效、不弹错误窗。
- 无文档、未选中或选中多个对象时直接返回，不弹窗。
- 输入非法时静默放弃，不打断当前操作。
- 运行日志写入统一诊断通道，对用户隐藏。

## 两层各自独立

- **强制 JSX 模式**，或插件不可用 / 命令未部署时：脚本用自己的输入框，用
  `translate()` 平移整组，失败时回落到已验证的原生 Action move，独立完成全部功能。
- **自动 / C++ 模式**：由插件弹它自己的原生输入框并独立完成平移，
  脚本派发菜单命令后立即返回。
- 删掉任一层，另一层仍能完成全部功能。插件菜单命令独立运行时同样自己弹输入框，
  不依赖脚本传参。

## 当前状态（2026-11-13）

- JSX 与 AIP 两层都已部署（Illustrator 2026），`HG Tools` 菜单里也有
  `HG Move Child Objects to XY (Move Whole Group)` 这一项，可以独立直接点。
- 自动 / C++ 模式走插件的原生输入框并完成平移；强制 JSX 模式或插件不可用时，
  脚本用自己的输入框和平移逻辑独立完成，不受影响。
- 已在 Illustrator 2026 实机验证：目标坐标精确落点、整组同步位移、选区恢复、
  三模式分流、无选中与多选静默分支全部通过。

## 当前限制

- 只处理单选。
- 多层组默认移动最外层父组。
- 不自动识别灰色底框，用户选中的对象就是基准对象。
- 深层隔离模式下父组可能无法变换，请退出隔离模式后再运行。
- 目标坐标按点（pt）计算；画板尺寸改变后需要重新运行脚本。
