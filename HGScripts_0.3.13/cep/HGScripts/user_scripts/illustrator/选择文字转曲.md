# 选择文字转曲

## 用途

把文字转成轮廓（转曲），方便出片、送印或避免对方缺字体。支持 C++ 加速，脚本管理器里可切换 C++ / JSX 运行模式。

## 怎么用

1. 打开需要处理的文档。
2. 想只处理一部分：先选中对象（可以直接选组）。
3. 想把整篇都转掉：什么都不选，直接运行 `选择文字转曲.jsx`。

## 处理规则

- 有选中对象时：只处理选中范围内的文字，范围外的文字保持原样。
- 没有选中对象时：处理当前文档里的全部文字。
- 选中组时，组里的文字也会处理；点文字、区域文字、路径文字都会处理。
- 锁定对象、隐藏对象、锁定图层和隐藏图层上的文字会静默跳过。
- 如果选中的对象里没有文字，脚本不做任何事，不会顺手把整篇文档转掉。
- 处理完成后，转出来的轮廓会处于选中状态，和 Illustrator 自带「创建轮廓」一致。
- 转曲时会把字体、字号、颜色、原文写进轮廓组的隐藏备注（只记录主字体，备注里附全部字体清单），之后可用 `字体还原.jsx` 重建可编辑文字。

## 注意

- 转曲后文字不能再编辑，请先存一份原稿或确认已经保存；需要回改文字时用 `字体还原.jsx`。
- 带不透明度蒙版的文字转曲时不留痕（Illustrator 脚本读不到蒙版），这类轮廓无法用字体还原。
- 转曲会受 Illustrator 自带「创建轮廓」的限制影响，例如符号里的文字不会被处理。
- 支持的 Illustrator 版本以当前安装目录里的 `.aip` 为准；旧版本没有 C++ 命令时会自动改用纯 JSX 处理。
