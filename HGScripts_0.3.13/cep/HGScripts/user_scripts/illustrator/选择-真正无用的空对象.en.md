# Select Truly Useless Empty Objects

## Purpose

Selects empty path objects (no fill, no stroke) in the current Illustrator document.

Selects only, does not delete, so you can review before removing.

## How to Use
1. Open an Illustrator document.
2. Run the script.
3. The status bar shows how many empty objects were selected.
4. Review the selection and remove objects if needed.

## Notes
- Locked and hidden objects are skipped.
- Check the result before saving production artwork.
