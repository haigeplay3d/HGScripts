# Selection to Custom Color, Others to Custom Color

## Purpose

Changes the selected artwork to one custom color and the remaining artwork on the active artboard to another custom color.

## How to Use
1. Open an Illustrator document.
2. Select the artwork to turn into the first color.
3. Run the script.
4. Choose the color for the selected artwork.
5. Choose the color for the remaining artwork.

## Notes
- Only artwork whose center is inside the active artboard is treated as "remaining".
- Check the result before saving production artwork.
- When the 2023-2027 C++ plug-in is installed, the script uses the accelerated command `HGSelectionCustomOthersCustom`; if it is missing or fails, it falls back to plain JSX with identical behavior.
