# Child Object Move to XY - Move Group

Added on 2026-11-12 as a sibling of "Child Object Resize - Scale Group": you select one
child object inside a group, and the entire parent group is what actually gets moved.
Enter a target X / Y and the script translates the whole parent group so the selected
child's center lands on that coordinate.

## How to Use

1. Select exactly one child object inside a group as the reference object.
2. Run the script.
3. The dialog pre-fills X and Y with the current coordinates. Change one field to move
   on that axis only; leave a field empty to keep that axis unchanged.
4. The script finds the outermost parent group and translates the whole group.
5. The original selection is restored.

## Coordinate Convention

- Anchor: the center of the object's bounds, matching the default reference point in
  the Transform panel.
- Origin: the top-left corner of the artboard containing the object's center;
  X increases to the right, Y increases downward.
- Bounds: follows the Illustrator "Use Preview Bounds" preference, which decides
  whether stroke width is included.
- Multiple artboards: the artboard containing the object's center wins; if the object
  lies outside every artboard, the nearest artboard is used.

## Accepted Input

- `120`: treated as 120 px/pt.
- `-30`: negative values are allowed, so you can move outside the artboard.
- `50mm`, `5cm`, `2in`, `10pt`, `100px`.
- Empty: that axis stays unchanged. Leave both empty to do nothing.

## Silent Behaviour

- Only one target-coordinate dialog; no success message, no sound, no error dialog.
- With no document, no selection, or multiple objects selected, it returns silently.
- Invalid input is discarded silently; your current work is never interrupted.
- Runtime events go to the shared diagnostic channel and stay hidden from the user.

## Two Independent Layers

- **Forced JSX mode**, or when the plug-in is unavailable / the command is not deployed:
  the script shows its own dialog, translates the group with `translate()`, and falls
  back to the verified native Action move if that fails. It completes the whole feature
  on its own.
- **Auto / C++ mode**: the plug-in shows its own native dialog and performs the move
  independently. The script dispatches the menu command and returns immediately.
- Removing either layer still leaves the other fully functional. Running the plug-in
  menu command on its own also shows its own input dialog; it never depends on values
  passed by the script.

## Current State (2026-11-13)

- Both layers are deployed for Illustrator 2026. The `HG Tools` menu also has
  `HG Move Child Objects to XY (Move Whole Group)` as a standalone entry.
- Auto / C++ mode uses the plug-in's native dialog and performs the move there.
  Forced JSX mode, or a missing plug-in, uses the script's own dialog and move
  logic and stays fully functional.
- Verified on a live Illustrator 2026 host: exact target coordinates, whole-group
  translation, selection restore, all three modes, and the no-selection /
  multi-selection silent branches.

## Current Limits

- Single selection only.
- Nested groups: the outermost parent group is moved.
- The reference object is never auto-detected; whatever you selected is the reference.
- If deep isolation mode prevents transforming the parent group, exit isolation mode
  and run the script again.
- Target coordinates are computed in points; run the script again after changing the
  artboard size.
