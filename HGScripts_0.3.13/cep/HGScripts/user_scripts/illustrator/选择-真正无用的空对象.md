# 选择-真正无用的空对象

## 用途

选中文档中没有填充、没有描边的空路径对象（真正无用的空对象）。

只选中、不删除，方便你检查后再自行处理。

## 怎么用

1. 打开 Illustrator 文档。
2. 运行 `选择-真正无用的空对象.jsx`。
3. 状态栏会显示「已选中 N 个空对象」。
4. 检查选中的对象，根据需要删除或处理。

## 结果

- 脚本会选中无填充、无描边的路径对象。
- 不会自动删除对象。
- 状态栏显示本次选中的空对象数量。

## 注意事项

- 运行前建议保存或备份文件。
- 锁定、隐藏对象通常不会被处理。
- 优先尝试更快的插件方式，插件不在时自动改用纯 JSX，不影响使用。
