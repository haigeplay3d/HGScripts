# illustrator坐标转换器

## 来历

原始版本是 2024-05-14 的 `AI坐标系转UV坐标系和OC坐标系`，署名「酒瓶建模师海哥」。用途是把 Illustrator 画板里的版面位置和尺寸，换算成 C4D / Octane 贴图需要的 UV 与 OC 参数：`宽/画板`、`高/画板` 就是 Octane 的纹理缩放，`OC(x)`、`OC(y)` 就是纹理位置。这样在 AI 里排好的瓶标、包装图案能按同一套比例贴到 3D 模型上，不用手工量。

注意：来历里提到的「AI」指 Adobe Illustrator，不是人工智能。

## 用途

读取选中对象的位置、尺寸和画板比例，并转换成 UV、Octane 等常用参数。

适合把 Illustrator 里的版面位置转给渲染、贴图或其它软件使用。

## 怎么用

1. 打开 Illustrator 文档。
2. 选中一个对象。
3. 运行 `illustrator坐标转换器.jsx`。
4. 在面板中点击计算按钮。
5. 查看或复制需要的坐标参数。

## 注意事项

- 需要先选中对象。
- 结果基于当前活动画板和选中对象计算。
- 如果对象位置或画板改变，需要重新计算。
