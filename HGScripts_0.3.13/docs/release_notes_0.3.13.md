# HGScripts v0.3.13 更新说明

2026-11-27。本版精简 Illustrator 原生插件菜单，让菜单只列出正式脚本真正用到的功能。

## 更新内容

- 「HG Tools」菜单不再列出 15 个过时命令：长边设为 1024、噪声生成器、染白/染黑等黑白遮罩命令、被「子对象对齐画板」六合一取代的旧对齐命令，以及清理空对象。正式插件里的菜单项现在与正式脚本一一对应，点开有对应功能。
- 开发中功能（按颜色/按对象导出 mask、选择管理器）移到「HG Tools Dev」菜单，正式安装包不含开发版插件，日常使用时看不到这些入口。
- 重编插件时自动核对菜单命令与正式脚本是否一一对应：多了旧命令或少了脚本入口都会当场报错，避免过时命令再次混进正式版。

## 兼容范围

- Illustrator 2021 及以后可使用 CEP 面板和普通 JSX 脚本。
- Windows C++ 加速插件支持 Illustrator 2023、2024、2025、2026、2027，每个年份使用对应 SDK 编译的统一 `HGScriptsNative.aip`。
- 本安装包仅支持 Windows，暂不支持 macOS。

## 验收提示

安装后完全退出并重新打开 Illustrator，确认「HG Tools」菜单里不再出现长边 1024、噪声生成器、Turn Selection White/Black 等已移除项；需要在 C++ 加速模式下试跑一个受支持脚本确认菜单功能正常。开发中功能不在正式安装包内。
