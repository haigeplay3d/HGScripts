# 记录当前文档图层可见.jsx 说明

## 脚本用途

永久记录 Photoshop 当前文档所有图层和图层组的可见状态。

## 保存位置

记录会保存到本机：

`%APPDATA%\HGScripts\data\photoshop\layer_visibility\`

同一个 PSD 多次运行会覆盖同一份记录。

记录成功后，脚本会自动清理同目录中最后修改时间早于 2 天的旧 JSON 记录；不限制记录数量。

## 记录内容

- 文档名称、路径、尺寸和颜色模式。
- 每个图层/图层组的 `layer.id`。
- 图层名、图层类型、层级路径、同级顺序和 `visible` 状态。

## 使用流程

1. 打开需要记录状态的 PSD。
2. 调整好图层可见性。
3. 在 HGScripts 面板中运行 `记录当前文档图层可见.jsx`。

## 注意事项

- 脚本静默执行，不弹窗。
- 兼容没有内置 `JSON.stringify` 的 Photoshop ExtendScript 环境。
- 如果文档未保存，会用文档名和尺寸生成记录 key；更推荐先保存 PSD。
- 运行错误会写入隐藏日志：`%APPDATA%\HGScripts\logs\photoshop\记录当前文档图层可见.log`。
