# 单一色转其它色

## 用途

以第一个选择对象的单一颜色为样本，把所有同色对象改成自定义颜色。支持 C++ 加速，脚本管理器里可切换 C++ / JSX 运行模式。

## 怎么用

1. 选中一个取样对象。
2. 运行 `单一色转其它色.jsx`。
3. 在颜色选择器里选择新颜色。

## 匹配规则

- 样本只有填充、只有描边，或填充和描边同色时才执行。
- 目标只要所有存在的填充/描边都等于样本色，就会被改成新颜色。
- 样本无填充无描边，或填充和描边不同色时，不执行。
- 本次实际改色的对象，不透明度会恢复为 100%。

## 注意

- 组和复合路径会递归处理。
- 不会执行“扩展外观”，不会拆散原有对象结构。
- 无效取样会静默退出，不弹窗。
