# 同色转白其余转黑

## 用途

把当前画板中的同色对象转成白色，其它有颜色的对象转成黑色。

适合快速制作黑白遮罩、材质 mask、同色区域检查。

## 怎么用

1. 打开 Illustrator 文档。
2. 激活要处理的画板。
3. 选中一个对象或一个组，作为取样来源。
4. 运行 `同色转白其余转黑.jsx`。

## 结果

- 和取样颜色相同的填充或描边会变成白色。
- 和取样颜色不同的填充或描边会变成黑色。
- 没有填充、没有描边的对象不会新增颜色。
- 本次实际改色的对象，不透明度会恢复为 100%。
- 锁定、隐藏、图片、符号等对象会跳过。

## 取样规则

- 优先取选中内容里的填充色。
- 没有填充色时，才取描边色。
- 如果选中的是组，会自动从组里面寻找第一个可用颜色。

## 注意事项

- 这是批量改色脚本，会直接修改当前画板内容。
- 建议先复制文件或在副本中测试。
- 只处理当前活动画板内的对象，避免影响其它画板。
- 不会执行“扩展外观”，不会拆散原有对象结构。
- 渐变和图案可以处理，但按 Illustrator 里的同一个定义判断是否相同。
