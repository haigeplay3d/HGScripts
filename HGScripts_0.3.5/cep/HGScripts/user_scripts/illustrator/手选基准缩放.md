# 手选基准缩放

急用版 JSX。

## 用法

1. 在 Illustrator 中手动选中 1 个基准对象。
2. 运行脚本。
3. 在弹窗里填写目标宽度、目标高度，输入框默认留空；二者可以只填一个，也可以两个都填。
4. 脚本会找到该对象所属的最外层父组，并等比缩放整个父组。
5. 缩放后保持基准对象中心坐标不变。

## 静默规则

- 保留目标尺寸输入框。
- 宽度和高度合并在同一个入口里输入。
- 不弹出成功提示。
- 条件不满足时直接返回。

## 双输入规则

- 只填宽度：按目标宽度等比缩放。
- 只填高度：按目标高度等比缩放。
- 同时填写宽度和高度：允许非等比缩放，让基准对象达到指定宽高。

## 支持的输入

- `1024`：按 `1024 px/pt` 处理。
- `1024px`
- `1024pt`
- `1024mm`
- `10cm`
- `4in`

## 当前限制

- 只处理单选。
- 多层组默认缩放最外层父组。
- 不自动识别灰色底框，用户选中的对象就是基准对象。
- 如果深层隔离模式导致父组无法变换，请退出隔离模式后再运行。
- 自动/C++ 模式下优先调用 AIP 原生命令 `HGBasisScaleToSize`，由 AIP 弹出中文双输入框并按同一规则处理；如果插件不可用，才回退到 JSX 双输入框与 JSX 原生 Action 路径。
- 强制 JSX 模式下不调用 AIP，直接使用 JSX 双输入框与 JSX fallback。
