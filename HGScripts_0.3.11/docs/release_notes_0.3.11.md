# HGScripts v0.3.11 更新说明

2026-11-20。本版纳入开发完成的坐标转换器，统一脚本与插件的命名和按钮口径，修好两个安装后暴露的问题；尚未完成的脚本与 mask 相关功能暂不进升级包，源码保留。

## 更新内容

- 坐标转换器脚本与插件统一为三个按钮：「计算选中」量取所选对象，「生成报告」只打印面板当前数值，「自定义计算」按你最后改动的输入框反算同一条链上的其它数值；插件版还支持点参数名复制、右键粘贴。
- 坐标转换器脚本改名为「illustrator坐标转换器」，插件面板标题同步统一，英文显示名与图标一并更新。
- 「选中对象按图层复制分组」改名为「复制选中对象按原图层分组」，并补上专属面板图标。
- 本机面板固定只保留正式版，不再出现独立开发版入口，避免误开旧面板。
- 修好装完 0.3.11 后脚本列表里所有图标变成同一个默认图标的问题，每个脚本的专属图标都恢复正常。
- 修好脚本目录弹窗里三个「打开文件夹」按钮点了没反应的问题，现在点一下就会打开对应的脚本目录。
- 修好「单色转自定义颜色-其它转自定义颜色」结果全变成其它颜色、以及同色对象被拆成两拨分别变色的问题。

## 升级包范围

本版升级包只收开发完成的功能。以下脚本只是暂时不进升级包，源码保留，将来可能再删，并非删除：六个对象两行三列最大化、复制选择对象到新画板、导出选择对象为长边1024AI、选择对象长边设为1024，以及全部 mask 相关脚本。正式 AIP 只收已完成功能；测试合集只在开发机使用，不进升级包。

## 怎么确认修好了

1. 安装或覆盖升级后打开 Illustrator，在「窗口 > 扩展」里打开面板，脚本列表应显示各自不同的图标，而不是一律显示通用图标。
2. 打开脚本目录弹窗，点任意「打开文件夹」按钮，应直接打开对应目录。
3. 在面板里运行「illustrator坐标转换器」，确认只有「计算选中」「生成报告」「自定义计算」三个按钮；改任一输入框后，同一条换算链上的其它数值会同步更新。
4. 运行「复制选中对象按原图层分组」，确认新图层的组顺序与原稿一致，脚本名和图标已更新。
5. 对嵌套组里的同色对象运行「单色转自定义颜色-其它转自定义颜色」，确认样本色和其它色按设定分开变化，同色对象不会被拆成两拨。

## 升级与兼容

- 覆盖安装与卸载后重装均支持；卸载会删除面板设置、脚本目录配置与内置脚本文件夹。
- 兼容 Illustrator 2021 及以后、Photoshop / InDesign 的 CEP 宿主范围与 0.3.10 相同；C++ 加速插件随四年份正式 AIP 一起提供。
