# 选择对象改颜色_排除一些

## 用途

把选中对象的填充和描边改成你选的颜色，同时跳过你指定的「排除颜色」——这些颜色保持不动。

## 怎么用

1. 打开 Illustrator 文档，选中要改颜色的对象。
2. 运行 `选择对象改颜色_排除一些.jsx`。
3. 第一次弹窗选「要改成的颜色」。
4. 之后反复弹窗选「要排除的颜色」，选完一个还会再弹；全部选完后直接点「取消」结束。
5. 第一次排除颜色就点「取消」＝ 不做排除，全部改成目标颜色。

## 结果

- 有填充的对象，填充改成目标颜色；有描边的对象，描边改成目标颜色。
- 颜色等于某个「排除颜色」的填充或描边保持不变（填充、描边各自单独判断）。
- 没有填充或描边的位置不会新增颜色。
- 组、复合路径和文字会尽量处理；不执行扩展外观、不拆散对象结构。
- 实际改颜色或被处理到的对象，不透明度恢复到 100%。

## 匹配方式

按精确相等判断：你选了什么颜色，就只排除这些颜色。同一个颜色若颜色空间不同也算不同颜色（例如 RGB 黑与 CMYK 黑不会被当作同一个排除颜色）。

## 注意事项

- 只处理当前选中对象。
- 图片、锁定、隐藏对象会跳过。
