# Change Selection Color - Exclude Some

## Purpose

Recolor the selected artwork to a color you pick, while leaving the colors you exclude untouched.

## How to Use

1. Open an Illustrator document and select the artwork.
2. Run the script.
3. Pick the target color in the first dialog.
4. Keep picking colors to exclude; each picked color is added to the exclude list. Click Cancel when done.
5. Skipping the first exclude pick applies the color to everything (no exclusions).

## Notes

- Fill and stroke are processed independently; a fill or stroke equal to an excluded color is kept.
- Matching is exact. The same color in different color spaces (e.g. RGB black vs CMYK black) is treated as different.
- Check the result before saving production artwork.
