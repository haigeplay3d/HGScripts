# 复制选中对象按原图层分组

## 做什么

把当前选中的对象**各复制一份**，按「原件所在的图层」归堆，每一堆打成一个组，组名就是那个图层的名字；再新建一个随机 6 个字母命名的最上层图层，把所有新组放进去。

**原对象、原图层、原组一律不动。** 没被选中的对象也原地不动。

## 怎么用

1. 在 Illustrator 里选中要整理的对象（可以跨多个图层，可以框选）。
2. 运行本脚本。
3. 图层面板最上方会出现一个 6 字母名称的新图层；展开它，里面是按原图层名命名的一组组副本。脚本跑完会顺手选中这些新组，方便一眼看到结果。

脚本不弹窗、不保存文档。不满意可以直接删掉这个新图层，或者关掉文档不保存，原稿完全没被改过。

## 效果示意

```
新图层 ABCDEF                  ← 最上层，名字每次随机
├─ 组「花」                   ← 「花」图层里被选中对象的副本
├─ 组「红色线」               ← 「红色线」图层里被选中对象的副本
├─ 组「底色」                 ← …
└─ …
原图层「花」「红色线」「底色」  ← 原件原样保留
```

## 已知边界

- 副本和原件**位置完全重合**，画布上看不出变化，要看结果请展开新图层或隐藏原图层。
- 同名图层会合并成同一个组；组名真的撞车时自动加 ` (2)`。
- 组的排布按图层面板从上到下，用来还原原来的前后遮挡。2026-11-12 实机反馈「组顺序反了」已修正：`groupItems.add()` 每次把新组放在最上层，所以脚本改为按原图层从下往上创建组。
- 选中的对象如果本来嵌在某个组里，只会复制它自己，不会把整个原组一起带过来。
- 极少数宿主不允许复制的对象会被跳过，计数写进隐藏日志（ExtendScript 控制台，`$.writeln`），不影响其他对象。
- 脚本不写盘、不调用保存；复制品是叠在原稿上的**另一套**，后续只改副本时，别忘了下面还有原件。
