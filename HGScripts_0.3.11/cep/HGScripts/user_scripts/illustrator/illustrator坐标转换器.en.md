# Illustrator Coordinate Converter

## Origin

The original version dates from 2024-05-14 and was named "AI coordinate system to UV and OC". It converts artboard-relative position and size into the UV / Octane texture parameters used in C4D workflows: width/artboard and height/artboard are the texture scale, while OC(x) and OC(y) are the texture offset. That lets labels and packaging artwork laid out in Illustrator be mapped onto a 3D model with matching proportions instead of measuring by hand.

Note: "AI" here means Adobe Illustrator, not artificial intelligence.

## Purpose

Converts selected-object coordinates and dimensions into common production coordinate formats.

## How to Use
1. Open an Illustrator document.
2. Select the target artwork if required.
3. Run the script.

## Notes
- Check the result before saving production artwork.
