# Restore Text from Outlines

## Purpose

Brings text converted by "Outline Selected Text" back to editable text. When outlining, the script writes the font, size, color and original contents into a hidden note on the outline group; this script reads those notes and rebuilds the text in place.

## How to Use

1. Open a document processed by "Outline Selected Text".
2. To restore only part of it: select the outline groups first (selecting the group directly is fine).
3. To restore the whole document: select nothing and run `字体还原.jsx` (Restore Text from Outlines).

## Rules

- Only outline groups carrying the note are processed; objects without a note are untouched.
- The rebuilt text is placed in front of its outline group at the same position; **the original outline group is kept**, delete it yourself once confirmed.
- Each outline group is restored only once; re-running does not duplicate text.
- Locked or hidden objects, and objects on locked or hidden layers, are skipped silently.
- If a recorded font is missing on this machine, that outline is skipped; all missing fonts are listed once at the end.
- No dialog on full success; a single summary appears only when fonts are missing or something failed.

## Notes

- Only the **primary font** (font of the first character) is recorded; the note also carries the full font list, but mixed-font text is restored uniformly in the primary font.
- Path text loses its original path when outlined, so it is restored as point text at the outline position and needs manual adjustment.
- Position is aligned to the outline bounds and may differ slightly from the original text baseline.
- Text with an opacity mask gets no note when outlined (scripts cannot read the mask), so such outlines cannot be restored.
- Outlines created by older versions (without notes) cannot be restored.
