# HGScripts v0.3.14 更新说明

2026-11-28。修复一批颜色类脚本点了没反应的问题，并给发布校验加上脚本编码关。

## 更新内容

- 修好 8 个颜色类脚本（单色转自定义及其「其它转自定义」、选择对象转自定义、黑白互换、同色选择严格/宽松、排除一些、选择转自定义其余转自定义）点了没反应的问题：公共颜色库文件带中文但没有 UTF-8 文件头，Illustrator 加载时报「无法转换」，脚本在读取颜色库那一步就中断了；现在补上文件头，8 个脚本都能正常加载运行。插件菜单命令本身没有问题。
- 发布自检加了一道脚本编码关：以后任何脚本文件里写了中文却缺 UTF-8 文件头，发版校验会当场报错，不再出现「静态检查全绿、脚本却全都点不动」只能靠实机碰运气的情况。所有带中文的脚本文件已统一补齐文件头。

## 兼容范围

- Illustrator 2021 及以后可使用 CEP 面板和普通 JSX 脚本。
- Windows C++ 加速插件支持 Illustrator 2023、2024、2025、2026、2027，每个年份使用对应 SDK 编译的统一 `HGScriptsNative.aip`。
- 本安装包仅支持 Windows，暂不支持 macOS。

## 验收提示

安装后完全退出并重新打开 Illustrator，确认面板能正常出现，再点一次「单色转自定义颜色」确认脚本正常加载。
