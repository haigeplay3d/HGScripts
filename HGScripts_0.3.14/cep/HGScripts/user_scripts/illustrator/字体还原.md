# 字体还原

## 用途

把「选择文字转曲」转掉的文字还原成可编辑文字。转曲时脚本会把字体、字号、颜色、原文写进轮廓组的隐藏备注（note），本脚本读取这些备注，在原位置重建文字。

## 怎么用

1. 打开用「选择文字转曲」处理过的文档。
2. 想只还原一部分：先选中轮廓组（可以直接选组）。
3. 想整篇还原：什么都不选，直接运行 `字体还原.jsx`。

## 处理规则

- 只处理带留痕备注的轮廓组；没有备注的对象不受影响。
- 还原出的新文字放在原轮廓组前面、同一位置；**原轮廓组保留不动**，确认无误后可自己删掉。
- 每个轮廓组只还原一次，重复运行不会重复生成。
- 锁定对象、隐藏对象、锁定图层和隐藏图层上的对象会静默跳过。
- 本机缺少留痕里记录的字体时，对应轮廓不还原，结束时统一列出缺的字体名。
- 全部顺利还原时不弹窗；有缺字体或失败才弹一次汇总。

## 注意

- 只记录**主字体**（第一个字符的字体）；留痕里附了全部字体清单，但混排文字还原后会统一成主字体。
- 路径文字转曲后原路径已不存在，还原时按点文字放回轮廓位置，需要手工再调整。
- 还原位置按轮廓外框对齐，和原始文字基线可能有细微偏差。
- 带不透明度蒙版的文字转曲时不留痕（Illustrator 脚本读不到蒙版），这类轮廓无法还原。
- 旧版本转曲（没有留痕）的轮廓无法还原。
