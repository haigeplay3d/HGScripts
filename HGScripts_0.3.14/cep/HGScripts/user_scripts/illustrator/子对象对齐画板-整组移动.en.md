# Child Object Align to Artboard - Move Group

Select one child object as the reference, then click one of the six alignment icons. The script moves the **outermost parent group** so that the selected child object aligns with the left edge, horizontal center, right edge, top edge, vertical center, or bottom edge of its artboard.

- Works only when exactly one object is selected. With no selection or multiple objects, no dialog appears and the script returns silently.
- The whole group (outermost parent) is moved, not just the selected child object. With no parent group, the object itself is moved.
- Clicking an icon runs the alignment immediately and closes the window. There is no OK button; closing the window cancels.
- AIP and JSX each have their own small dialog. When the plug-in is installed it shows its own dialog; when it is missing, the script shows its own. Remove either layer and the other still performs all six alignments.
- Bounds, artboard selection and selection restore follow the same rules as the original six alignment scripts.
- This script replaces the six former "Manual Reference Align to Artboard - *" entries. Sizing is handled separately by "Child Object Resize - Scale Group"; the two do not affect each other.
