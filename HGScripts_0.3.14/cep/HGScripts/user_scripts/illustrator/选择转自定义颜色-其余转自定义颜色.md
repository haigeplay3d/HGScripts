# 选择转自定义颜色-其余转自定义颜色

## 用途

把当前选中的对象改成第一个自定义颜色，把活动画板内其余对象改成第二个自定义颜色。

## 怎么用

1. 打开 Illustrator 文档。
2. 选中要改成第一个颜色的对象。
3. 运行 `选择转自定义颜色-其余转自定义颜色.jsx`。
4. 第一次拾色器选择「选中对象要转成的颜色」。
5. 第二次拾色器选择「其余对象要转成的颜色」。

## 结果

- 选中的对象改为第一个自定义颜色。
- 活动画板内（对象中心在画板范围内）的其余对象改为第二个自定义颜色。
- 画板外的对象不改。
- 不新增填颜色、不新增描边。
- 本次实际改颜色对象及其父级容器，不透明度会恢复为 100%。

## 注意事项

- 只处理活动画板内的对象，其余对象按「中心点是否落在活动画板内」判断。
- 组、复合路径和文字会尽量处理。
- 不会执行「扩展外观」，不会拆散原有对象结构。
- 取消任意一次拾色器时不会改颜色。
- 装有 2023–2027 版 C++ 插件时优先走加速命令 `HGSelectionCustomOthersCustom`；插件不在或调用失败会自动改用纯 JSX，使用方式不变。
