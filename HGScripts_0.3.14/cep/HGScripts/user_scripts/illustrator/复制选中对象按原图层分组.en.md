# Copy Selected Objects, Group By Original Layer

## What it does

Duplicates each currently selected object, buckets the copies by the layer their
original sits on, makes one group per bucket (group name = that layer's name),
and places all groups in a new top-most layer with a random 6-letter name.

**The originals, their layers and their groups are never touched.** Art that was
not selected stays exactly where it was.

## How to use

1. In Illustrator, select the objects to reorganize (they may span several
   layers; a marquee selection is fine).
2. Run this script.
3. A new 6-letter layer appears at the top of the Layers panel. Expand it to see
   one group per source layer. The script selects the new groups on completion so
   the result is visible immediately.

The script shows no dialogs and does not save the document. To undo, just delete
the new layer, or close the document without saving — the original artwork is
unchanged.

## Result sketch

```
New layer ABCDEF               <- top-most, name is random each run
|- Group "Flowers"            <- copies of selected art on layer "Flowers"
|- Group "Red Lines"          <- copies of selected art on layer "Red Lines"
|- Group "Background"         <- ...
`- ...
Original layers               <- left exactly as they were
```

## Known limits

- Copies sit **exactly on top of** their originals, so the canvas looks
  unchanged. Expand the new layer or hide the source layers to inspect the result.
- Layers sharing a name are merged into one group. A genuine group-name clash
  gets an automatic ` (2)` suffix.
- Groups follow Layers-panel order (top to bottom) to restore the original
  stacking. Fixed after a live-host report on 2026-11-12: `groupItems.add()`
  places each new group on top, so groups are now created bottom-to-top.
- If a selected object is nested inside an existing group, only that object is
  duplicated; the enclosing group is not carried over.
- A rare object the host refuses to duplicate is skipped and counted in the
  hidden log (ExtendScript console, `$.writeln`); other objects are unaffected.
- Nothing is written to disk and the document is not saved. The copies are a
  **second set** stacked over the originals — remember the originals are still
  underneath if you later edit only the copies.
