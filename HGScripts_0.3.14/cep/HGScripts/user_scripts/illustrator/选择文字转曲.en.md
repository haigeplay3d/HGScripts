# Outline Selected Text

## Purpose

Converts text to outlines so artwork can be output or handed off without missing fonts. Works with the C++ accelerator, and the script manager can switch between C++ and JSX mode.

## How to Use

1. Open the document you want to process.
2. To process only part of the artwork, select the objects first (groups are fine).
3. To process the whole document, select nothing and run the script.

## Rules

- With a selection: only text inside the selection is converted; everything else is left untouched.
- With no selection: every text object in the document is converted.
- Text inside selected groups is converted; point text, area text and path text are all handled.
- Text on locked objects, hidden objects, locked layers or hidden layers is skipped silently.
- If the selection contains no text, nothing happens - the script does not fall back to converting the whole document.
- Outlined text ends up selected, matching Illustrator's own Create Outlines behavior.

## Notes

- Outlined text can no longer be edited. Keep a copy of the original file first.
- Text inside symbols is not processed, matching Illustrator's own Create Outlines behavior.
- If the installed plugin does not provide the C++ command, the script falls back to the pure JSX implementation automatically.
