# Child Object Resize - Scale Group

Formerly "Manual Reference Scale". Renamed on 2026-11-10 to match its sibling
"Child Object Align to Artboard - Move Group": you select one child object, and the
entire parent group is what actually gets scaled.

## How to Use

1. Select exactly one child object inside a group as the reference object.
2. Run the script.
3. Enter the target width and/or height in the dialog; both fields start empty.
4. The script finds the outermost parent group and scales the whole group. Filling
   only one field keeps the scaling proportional.
5. The reference object's center stays fixed and the original selection is restored.

## Silent Behaviour

- Keeps a target-size input dialog.
- Width and height are entered in one place.
- No success message is shown.
- With no document, no selection, or multiple objects selected, it returns silently.

## Two-Field Rules

- Width only: proportional scaling to the target width.
- Height only: proportional scaling to the target height.
- Both fields: non-proportional resize to the exact target width and height.

## Accepted Input

- `1024`: treated as `1024 px/pt`.
- `1024px`
- `1024pt`
- `1024mm`
- `10cm`
- `4in`

## Two Independent Layers

- **Auto / C++ mode**: the script dispatches the menu command to the plug-in and
  returns immediately. The plug-in shows its own native input dialog, performs the
  scaling on its own, and restores the reference center and selection itself.
- **Forced JSX mode**, or when the plug-in is unavailable: the script shows its own
  dialog and completes the scaling through the native Action / `resize()` fallbacks.
- Removing either layer still leaves the other fully functional. Running the
  plug-in menu command on its own also shows its own input dialog; it never depends
  on values passed by the script.

## Current Limits

- Single selection only.
- Nested groups: the outermost parent group is scaled.
- The reference object is never auto-detected; whatever you selected is the reference.
- If deep isolation mode prevents transforming the parent group, exit isolation mode
  and run the script again.
